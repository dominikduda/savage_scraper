How many times Savage Scraper confirms the page bottom before finishing. Try increasing this if scraping finishes too early. Default: 2.

How long each bottom check may wait for more page content. Try increasing this if scraping finishes before content has loaded. Default: 2600 ms.

During MCP browser operations, Savage Scraper temporarily brings its dedicated agent tab and Chrome window to the foreground and keeps them active, focused, and non-minimized while navigation and scraping run. If you switch tabs, focus another Chrome window, or minimize Chrome during an active MCP operation, Savage Scraper may temporarily restore the agent tab/window until the operation finishes. Previous Chrome state is restored on a best-effort basis afterward.

Enabling MCP website access gives Savage Scraper optional permission to access normal HTTP/HTTPS pages. Actual MCP navigation and scraping are additionally restricted by the configurable allowed_hosts whitelist and optional allowed_paths restrictions in savage_mcp. Missing or empty path entries allow all paths on an already-allowed host.
