ICON PLACEHOLDER

No custom icon is required for the extension to work.
Because manifest.json currently has no "icons" or action.default_icon entry,
Chrome will use its generic extension icon.

If you later add custom PNG icons, a common set is:
- icons/icon16.png
- icons/icon32.png
- icons/icon48.png
- icons/icon128.png

Then add them to manifest.json before publishing.
